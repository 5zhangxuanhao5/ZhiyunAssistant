# Internal Android integration contract

Android sources: app/src/main/java/cn/suike/slides/android. Native JavascriptInterface name NativeBridge.
- sync(method: String,payloadJson: String): String returns JSON {value: any} or {error: string}; only sandbox file primitives, cookie reads, app paths and validated resource registry map operations are synchronous. No networking/large image work on sync.
- post(id: String,method: String,payloadJson: String): void schedules async work; calls window.__androidReceive({id,value,error}) on UI thread. JS event entry window.__androidEvent({name,value}).
- Low-level bridge global window.androidNative: {call, sync, on}. App's window.zhiyun is higher-level JS services.

## Native operations
fs.exists {path}->boolean; fs.mkdir {path,recursive}; fs.list {path}->string[]; fs.readText {path}->string; fs.stat {path|fd}->{size,mtime,directory}; fs.open {path,flags}-> {fd}; fs.close {fd}; fs.fdPath {fd}->sandbox path; fs.write {fd,text?|base64?}->count; fs.read {fd,length}->base64; fs.rename {from,to}; fs.remove {path,recursive}; fs.copy {from,to} (from/to string or fd); fs.truncate {fd,length}; fs.readBytes {path}->base64; fs.writeBytes {path,base64}; fs.export {path,name}->saved path/uri.
File paths are absolute app files/cache roots only (and native-controlled export handles). OpenMode bits READ_ONLY=0 WRITE_ONLY=1 READ_WRITE=2 CREATE=64 TRUNC=512 APPEND=1024.
secret.get {alias}->string|null; secret.set {alias,value}; secret.remove {alias} (Android Keystore encrypted AES-GCM local app files).
cookies.get {url?}->[{name,value,domain,path,secure,httpOnly,expirationDate?}]; cookies.set {...}; cookies.remove {url,name}; cookies.flush {}; cookies.clear {}. Native login shares CookieManager and does NOT expose JS bridge to remote login pages.
http.request {url,method,headers,body?,timeout?,maxBytes?}-> {status,headers,body:string|base64,base64:boolean}. Only official allowlist HTTPS domains ZJU and approved classroom CDN and api.deepseek.com. Never ignore SSL errors; redirects validate each origin and strip credentials on origin change.
http.stream {url,method,headers,body?,timeout?,maxBytes?,requestId,backpressure?}->status (may return before completion); emits http.headers {requestId,headers}, http.data {requestId,base64,sequence?}, http.end {requestId}, http.error {requestId,error}. Native chunks <=64KiB. With backpressure:true JS acknowledges each data event after file/decoder listeners return: http.ack {requestId,sequence}. ACK/cancel bypass the worker queue. http.cancel {requestId}. Buffered responses are bounded; long video streams are written incrementally.
image.info {path}->{width,height}; image.pixels {path,width?,height?}->{base64,width,height,stride} RGBA; image.pack {base64,width,height,format,quality,crop?}->base64; image.crop {path,x,y,width,height,destination}->destination.
zip.create {folder,destination}; picker.save {name}->[sandbox temp path]; export.share {path,name} system SAF create document copies prepared file. picker.image {source?:'camera'|'gallery'} -> sandbox copied path|null (system chooser/camera).
resource.local {path,kind?}->https://appassets.androidplatform.net/resource/<unguessabletoken>/<name> URL; resource.remote {url,kind?}->same token URL. Native intercept serves local ranged files or bounded streaming approved remote, HLS manifests rewritten to resource URLs. Native only registers sandbox paths; add/remove resource map on logout. resource.resolve {url}->{local?,remote?}|null; resource.clear {}.
app.paths {} sync->{root,filesDir,cacheDir,tempDir}; app.login {} async->void once official classroom session successful; app.openExternal {url}; app.clipboard {text,html?,images?}; app.clipboardRead {}->{text,html}; app.drag {path}->boolean; app.downloads {active,count}; app.fullscreen {enabled}; app.cacheInfo {}->[{id,label,bytes}]; app.cacheClear {ids?}. Cache clearing excludes credentials, notes, offline files, resource registry and files still used by active transfers/export.
app.back emitted native back -> highlevel UI handles modals then route without logout. app.viewport event {width,height,insets:{top,right,bottom,left},folds:[{left,top,right,bottom,separating,orientation,state}],posture}. Preserve WebView across config changes. app.lifecycle {active:boolean} pauses periodic refresh while background (downloads can keep foreground service).

websocket.connect {socketId,url}; websocket.send {socketId,text}; websocket.close {socketId}; websocket.open/message/error/close events {socketId,data?,base64?,error?}. Socket endpoints must use /glue/ws, carry no forwarded credentials, and be allowlisted WSS or an exact endpoint trusted from the successful authorized official metadata response. No SSL bypass.
