# Android 功能迁移说明

本版保留现有智云助手的课程算法和学习页面，使用 Android 原生层承接官方登录、网络请求、文件、系统图片选择、剪贴板、拖拽和导出。不是把远端智云网页直接作为应用主界面。

## 服务覆盖

| 功能 | Android 实现路径 |
| --- | --- |
| 登录与自动恢复、离线登录状态 | 官方认证页面使用独立 WebView；主应用不向认证页注入桥接。会话与账号摘要通过 Android Keystore 加密保存。网络失败保留已登录账号及离线入口；主动退出清除会话。 |
| 今日、近两周、所有课程与课程广场 | 复用 Zhiyun 课程、教师、教室、学期、日期搜索、课次目录和权限算法；缓存先呈现，授权仍按平台实时结果检查。 |
| 收藏、稍后再看、学习进度 | 复用 CourseCollections 与 LearningProgress；账号独立，课次、视频位置、阅读页与转写阅读锚点持久化。 |
| 课件、转写与直播 | 保留原时间线、连续重复课件合并、讲解合并排序、无转写跳过和直播历史同步。官方 WebSocket 通过原生连接；后台关闭实时连接、暂停定时同步，回到前台补齐平台历史内容。 |
| 高清课件去黑边、概览 | 边界与相似性运算在独立 Web Worker；较大图片只传递受限预览进行边界识别，裁切由原生层在原分辨率文件上完成。 |
| 视频与多画面 | 保留原视频组件、播放位置/倍速/全屏/机位判断。原生层提供有凭据边界的流式资源和 Range 请求，HLS 清单重写成本应用资源地址。 |
| 下载、离线课程、批量管理 | 保留按日期/课程、并发数、排序、单节/全部暂停继续、失败部分重试、部分内容保存和缺失说明。流式写文件，避免把整段视频载入 JS 内存；进度与任务保存，进程重开后可继续。 |
| 课堂笔记与引用 | 保留多篇笔记、重命名、来源色、格式、图片和文字引用、时间点回溯、问答/速览引用及管理。资源展示地址保存时转换回账号的本机原文件，不把短期资源令牌写进笔记。 |
| 笔记导出 | 保留 TXT/HTML/Markdown、图片名称与多层目录 ZIP。通过 Android 系统文件保存器导出；准备好的大文件由原生层复制，不构造整个 ZIP 的 JS 字节数组。含图片的 HTML 会连同原图片打包，避免生成巨大的内嵌图片字符串。 |
| 课程问答、本页速览、跳过无实质讲解 | 保留自备 DeepSeek 密钥、模型、上下文范围、当前时间、跨课引用、流式输出、历史、速览版本及阅读位置；本次测试未使用用户付费密钥发起 AI 请求。 |
| 缓存管理 | 保留功能分类、开关、详情、多选和清理全部；额外列出 Android WebView/运行缓存。网页 HTTP 缓存开关接入 WebView，系统必要运行文件仍由 Android 管理；视频只保留当前播放缓冲，持久视频由离线下载提供。离线下载、笔记、收藏、进度和安全凭据分开保存。清理保留仍在使用的临时文件，避免打断下载和导出。 |
| 系统协作 | 系统图片选择器/相机、SAF 保存、文本/HTML/图片剪贴板与跨应用图片拖拽通过 Android 原生服务。 |

## 屏幕与输入

学习页面保留功能区、自由布局、大小、层级与锁定逻辑。小屏改为可滚动布局；平板和展开折叠屏使用更多横向空间；折叠分隔区域单独避让。折叠姿态、窗口尺寸和系统边缘信息不通过销毁学习页面来切换，避免丢失输入、笔记和播放位置。

保留触控、鼠标、触控板、键盘焦点及选择模型。Android 输入法确认和组合输入使用网页输入事件；问答 Enter 发送、Shift+Enter 换行的规则保留。实际折叠、系统输入法及多窗口行为还需结合设备验证记录判断。

## 已完成的服务回归

`tests/android-services.test.ts` 的 20 项测试覆盖桥接错误和解绑、分块文件读写/追加/截断、中文与 emoji 流式拆包、大视频流的大小上限、取消、网络异常、账号/进度/笔记/收藏离线重启、下载任务恢复、离线视频资源映射、原生导出清理、高清去黑边保留原分辨率，退出登录时的安全存储竞争、大图原子分块写入、HTML 图片打包，未来课程开课前不轮询且到点自动衔接、导出准备与保存期间的缓存保护，以及视频机位异步加载/换课竞争，以及实际网页缓存策略接入。

这代表服务迁移的行为验证，不代表每个真实教室、每款 Android 设备或所有课程源均已完成真机验证。真机与发布结果以发布说明和验证记录为准。

## 依赖平台或硬件的边界

- 课程访问遵循校园账号的实际权限；不绕过课程限制。
- 进入直播前的转写、课件或视频仅在平台提供时可追溯；无法提供时保留界面原因说明。
- 鸿蒙的互联设备图片能力没有可直接搬到 Android 的通用 API。Android 使用系统图片/文档提供者与相机；远端设备或扫描入口取决于手机系统提供的应用和服务。
- vivo X Fold5 可用于单折叠设备的展开/折叠真机验证；双折叠区域布局有算法回归，但不能把单折叠测试视作双折叠真机验证。
- Android 系统可能因强制停止、进程回收或厂商后台策略终止任务。下载任务和部分文件会保存，重开后支持继续；不能承诺系统强制停止后任务仍执行。
