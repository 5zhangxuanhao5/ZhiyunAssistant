# 智云助手 Android 版

Android 手机、平板和折叠屏客户端。沿用智云助手现有学习页面及课程、转写、笔记、AI、离线下载等共享逻辑，Android 系统负责官方登录、安全存储、文件、相机、媒体和窗口适配。各平台分别维护本机资料，不自动同步。

## 安装

在本仓库 [Releases](https://github.com/He-He-He-He-He-He/ZhiyunAssistant/releases) 下载 `ZhiyunAssistant-0.1.0-beta.2-Android.apk`，核对同一发布的 SHA256 后打开安装。适用于 Android 8.0 / API26 及以上，需 Android System WebView 100 或更新版本；不要求安装开发工具。安装确认由系统处理，不需要关闭系统安全防护。

一个 APK 可用于手机、Android 平板和折叠屏；代码不依赖 CPU 原生库。当前为预览版，实际验证范围见 [VERIFICATION.md](VERIFICATION.md)，功能对照见 [FEATURE_PARITY.md](FEATURE_PARITY.md)。

首次阅读隐私说明，在浙江大学官方登录页面登录。应用不保存校园密码。明确退出登录才清除本机身份；断网保留身份，可以查看已有的离线课程。首次安装在断网状态下不能建立此前没有的校园登录。

## 学习与窗口

- 我的课堂：今日、近两周、全部修读记录；课程广场搜索、日期和联动筛选；课程和课次收藏、稍后再看，保存学习进度。
- 高清课件与课堂转写按原时间线对应，支持去黑边、连续相邻重复课件合并及转写归并。非连续的相同图片保留各自位置。
- 视频主动加载，可寻址、倍速、全屏和切换真实机位。直播历史课件、转写及回放只使用平台实际提供且当前账号可访问的内容。
- 六个功能区可独立开关、拖动、缩放、调整图层；显式保存同功能组合、窗口大小和折叠状态的布局。
- 系统返回先关闭当前概览、布局等页面，再返回上一层；退出学习保留学习进度。

窄屏沿用纵向布局，打开较多功能区时可以滚动，避免把编辑区挤得过小。展开屏保留多功能区布局。折叠、旋转和分屏窗口改变时，学习进度、笔记、问答与视频实例保留；系统报告分隔铰链时，默认布局避开铰链。两个铰链按三个区域布局，半折横向铰链优先将视频放在上半区。双铰链布局目前需要对应硬件继续验收，单个 X Fold5 不能证明三折叠设备已经实测。

## 笔记、AI 与下载

笔记支持多篇管理、来源颜色、文字格式、光标位置插入图片或课程引用、重命名、时间回溯、Markdown / HTML / 纯文本与按课程日期打包导出。图片由系统图库或相机选择，导出使用 Android 系统保存文件页面。

课程问答、本页速览和跳过无实质讲解使用用户自己的 DeepSeek API 密钥；密钥通过 Android Keystore 加密。AI 材料按课件及讲解的顺序和时间提供，默认按需读取课件，稳定上下文与本机识图、回答缓存用于减少重复请求。启用 AI 才发送相关资料，实际费用由 DeepSeek 账户承担。回答不代替课堂原文。

下载可选择视频、课件、转写，保留并发数、队列顺序、单节暂停继续、失败部分重试、保存可用内容和明确的缺失原因。下载任务运行时使用系统前台服务；结束后停止，不常驻空任务。普通缓存与离线课程、笔记、进度、收藏分开，可分类查看和清理。网页 HTTP 缓存可关闭；播放器缓冲随播放释放，系统必要运行文件仍由 Android 管理。Android 系统停止进程或长时间后台限制后，未完成任务可以在应用中继续。

鸿蒙互联设备相机等平台特有能力使用 Android 系统可提供的图片/相机/分享入口，不宣称 Android 可以调用鸿蒙专用系统接口。

## 输入

文字使用 WebView 系统编辑与选择行为，不拦截数字键。课程问答 Enter 发送、Shift+Enter 换行；中文输入法候选确认不发送。聚焦视频后，空格播放暂停，左右键各跳15秒；聚焦课件、转写、速览后方向键翻页。Ctrl+A/C/V 按所在编辑或文字功能区处理，鼠标、触控板选择与触摸翻页分别处理。

实体键盘、鼠标与触控板的全部组合仍需要相应外设验收；自动事件检查不能替代所有实际外设。

## 构建

需要 Node.js 22+、JDK17、Android SDK36 和 Gradle8.13。首次安装 SDK 需要自行阅读并接受 Google 的 SDK 许可。工程含 Gradle Wrapper。

```sh
npm ci
npm run check
npm test
npm run build:web
./gradlew :app:testDebugUnitTest :app:assembleRelease
```

输出未签名 APK 在 `app/build/outputs/apk/release/`，请用自己的发行密钥签名。密钥、密码、`local.properties` 和个人资料不要提交到仓库。作者本机签名脚本 `scripts/android-build.py` 从工程外的凭据文件读取自己的密钥，不包含发行私钥，普通用户可直接安装 Releases 中已签名的 APK。

界面测试：`npx playwright install chromium` 后运行 `npm run test:ui`。这些测试使用明确的合成资料，不获取用户课程和付费 AI。Android 原生仪器测试使用应用独立测试目录，不删除用户笔记、缓存或会话。
