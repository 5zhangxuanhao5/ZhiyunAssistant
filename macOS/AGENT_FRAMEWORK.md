# 全局应用助手

Mac 1.8.1 在现有课程问答之外增加全局助手。标题栏“应用助手”在所有页面可用；学习工具栏也有入口。点击顶部小横条后进入调整状态，可以直接拖动横条移动窗口，或拖动四边、四角缩放；点击正文或窗口外取消调整。窗口没有原生右下角缩放柄。助手可收起或收为正常的学习功能区；收为功能区时使用学习面板的横条与布局规则。离开学习页面时自动浮动，回到学习页可恢复功能区形式。布局与对话按本机校园账号保存。

## 执行机制

`web/agent-runtime.js` 包含可扩展的 `AppActions` 注册表与 `AgentRunner`。应用通过 `getGlobalAssistant()` 注册有名称、描述、参数 schema 和执行函数的操作。框架验证参数、拒绝未知操作，再调用真实应用函数；不生成或执行 JavaScript、shell、原生桥接命令或任意 URL。

模型使用四个工具，遵循 Chat Completions 的完整 assistant/tool 往返协议：

1. `app_state`：当前页面、课次、进度、功能区和下载状态。
2. `app_actions`：按需查询操作目录和精确参数，避免每次发送整个能力目录。
3. `app_do`：执行注册操作并返回结果。
4. `app_interface`：读取当前可见界面的文字、按钮、输入框、选项及短期控件 ID。`interface_action` 可以操作这些刚观察到的控件；每次操作消耗快照，需要重新观察。弹窗打开时只枚举弹窗控件。密码、密钥、登录区域及助手自身排除。

专用操作覆盖页面导航、课表刷新、课程搜索与课次查询、进入学习、课件与转写读取、图片文字识别、时间与页码跳转、功能区和学习选项、视频播放/暂停/倍速/全屏、收藏/稍后再看、笔记读取/创建/写入/重命名/插入课件/导出、下载与队列管理、主题和自由布局。其余当前页面按钮通过界面工具操作。系统确认、认证、系统文件选择器继续由用户处理。

新增功能既可以注册专用操作，也可以通过现有可访问控件接入；不需要重新设计整个 agent。专用操作优先使用应用自己的编辑器、下载器和权限检查，避免操作两套互不一致的状态。

## 任务与数据

- 流式输出，操作过程与成功/失败可见，可以随时停止。停止或账号切换后不再执行下一步；已经完成的操作保留。切换课程不会自动终止全局任务。
- 课件、转写、笔记和页面内容作为资料，不作为新的操作授权。不会绕过课程权限，也不会向模型提供密钥、Cookie 或登录密码。
- 账号和任务代次隔离；每轮最多 128 次模型请求，工具次数、历史长度和返回内容有上限，重复无进展自动停止。长任务可由用户继续。
- 稳定系统前缀，按需查询工具描述、分页读课次/转写，较大的旧工具观测压缩（不截断模型思考回传或操作参数 schema），复用课件识别缓存。助手未运行时没有模型轮询。
- 对话保存为账号隔离的 `chats-agent.json`，归入“AI 对话记录”缓存。清理该缓存会同时清理助手的内存历史；不删除课堂笔记和离线资料。保留最近 20 个对话，每个最多 100 条用户/助手消息，模型只使用最近 12 条。

## AI 来源

`web/ai-connection.js` 统一课程问答、速览与应用助手的服务来源：

- 自动：有可用的个人 DeepSeek 密钥时优先个人 API；否则使用本机预置的浙大校内网关。
- 浙大校内网关：固定地址 `https://modelgateway.zju.edu.cn/v1/chat/completions`，固定模型 `deepseek-v4-flash-780k-local`。界面提示“仅在浙大内网环境下可用”。可以明确选择此来源覆盖个人 API。
- 个人 DeepSeek API：保留 Flash/Pro 与现有受保护密钥。

校园网关凭据仅通过本机设置存入独立钥匙串条目 `campus-model-gateway-v1`，不会返回给网页、写入普通缓存、源码、日志或安装包。公开分发版不包含私人预置密钥；其他设备需要合法的单独预置或配置个人 API。所有钥匙串操作禁止交互式授权，包括显式保存及兼容恢复。旧密钥不能静默读取时在应用内重新配置；不同构建使用独立受保护条目，非敏感索引仅存条目名称，不保存密钥。

校内模型实际返回“不支持多模态”：校内模式下，课件图片优先使用 `https://mcp.zju.edu.cn/api/protal/proxy/system/layout-parsing` 的校园版面 OCR（本机独立预置密钥 `campus-layout-ocr-v1`），提取 Markdown、公式和版面结构；服务不可用或未配置时用 Apple Vision 在本机识别文字。只缓存提取的文本，不缓存 OCR 返回的大体积可视化图片，再与有序转写供模型参考。结果注明限制，不声称理解未识别的图片或图表关系。个人 API 保留直接图片理解。

工具调用协议参考：[DeepSeek 官方文档](https://api-docs.deepseek.com/guides/tool_calls/)。

## 1.8.0 的执行体验与模型协议

- 浮动窗口与功能区共用主题的标题字号、圆角、面板及标题底色；位于学习功能区之上。收为功能区时交回正常布局图层。
- 执行时只有当前动作和简短输出预览，完成后收拢为可展开的步骤摘要。最终回答保留完整内容；不把每次“查询目录/读取状态”的旁白堆在对话中。内部 reasoning_content 不显示、不写入对话缓存。
- 操作目录提供全部能力摘要、中文近似关键词、精确名称与分页 schema。49 个专用操作加可观察界面控件，扩展了笔记/格式/引用、缓存保存设置、速览、常用功能顺序、等待资源、当前弹层、课程分组及后台课次资料读取。读取多课次不必反复切换用户的学习页面，不加载视频。
- 个人 DeepSeek 的应用助手使用当前 deepseek-flash/Pro、thinking enabled、reasoning_effort low/high/max（默认 high），16,384 输出预算；校内模型保留学校固定模型与兼容参数。工具轮次完整回传 reasoning_content，SSE 支持拆分行及 CRLF；截断参数不会执行。普通课程问答和速览的原有速度策略保持。
- 思考强度在个人 API 设置中可选。保持稳定系统前缀和工具定义，按需取操作 schema，复用已有课程资料与识别缓存；不会为收拢执行记录再发一次模型请求。
- 所有能力遵循应用自身账号、权限、确认及系统选择器流程；模型不能读取登录密码、API 密钥或 Cookie，也没有额外的系统命令执行接口。

接口依据：[思考模式与工具轮次](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 1.8.1 的窗口交互

浮动窗口的移动与缩放只由顶部小横条激活，边缘按方向显示缩放光标；选中边框随主题变化，没有常驻角标。拖动按动画帧更新，结束后保存几何信息，窗口顶部保持可达。空白对话不显示固定建议，不为生成建议额外调用模型。
