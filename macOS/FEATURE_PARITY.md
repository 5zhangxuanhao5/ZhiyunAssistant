# Mac 1.1.0 与鸿蒙学习体验对照

| 功能 | Mac 实现 | 验证方法 |
| --- | --- | --- |
| 课表、全部上课记录、课程广场 | 共用权限与课程模型；Mac 原生 WebKit 输入、联动筛选、日期选择 | API 模型和 DOM 集成 |
| 收藏、稍后再看、返回路径、学习进度 | 相同课程/课次模型与持久化规则，顶部导航 | 模型、真实完整 WebKit |
| 课件/转写配对与连续去重 | 共用时间线、相似度与黑边算法；配对显示分页 | 模型、DOM、WebKit |
| 自由功能区与六种功能 | 独立移动缩放、焦点、层级、锁定、保存布局 | 四边四角模型、DOM、WebKit 拖动 |
| 鼠标拖选与触控板阅读 | 原生文字选择；只将横向滚动和触摸横滑用于翻页 | 选区保留 DOM、真实 WebKit Range |
| 视频与全屏 | WebKit 视频、原生有界网络代理、Range、HLS 重写、倍速与快捷键 | 原生契约、真实合成 MP4 解码播放 |
| 多笔记、插入位置、格式、引用 | 可编辑来源框、系统光标/输入法、API 引用、缓存定位 | 专项 DOM 与 WebKit 插入/复制 |
| AI 问答、本页速览 | DeepSeek 流式与工具调用；稳定资料前缀、缓存、时间定位 | 模拟桥流式协议与模型/DOM；未付费实测模型输出 |
| 批量下载和离线队列 | 并发数、排队、暂停、续下、仅失败重试、部分保存、字节进度 | 下载模块、按钮和存储集成 |
| 本机缓存与账号隔离 | 钥匙串身份、账号目录、分类清理；笔记和离线资料独立 | 原生存储/路径契约与 DOM |
| 系统跨设备拍摄 | 没有复用鸿蒙互联设备接口；Mac 使用本机文件选择 | 不宣称一致 |
| 真正所有教室的直播历史 | 请求平台提供的历史并持续补齐；明确显示不存在的资源 | 每种实际教室媒体仍需要用户场景验收 |

测试证明对应实现执行过，不证明平台一定提供每门课的所有资源，也不证明所有外设、系统版本、媒体格式都已通过真实课程测试。
