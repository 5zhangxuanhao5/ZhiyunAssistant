# 智云助手 Mac 版 1.4.0

原生 macOS 窗口和系统 WebKit，复用鸿蒙版的智云接口、时间线、课件去重、黑边保护、权限、收藏与学习资料模型。1.1.1 修复重启后课程会话恢复，将账号操作移入系统标题栏，学习功能改为单行横向滚动，并补齐课件图片复制、跨应用拖出和全屏翻页。

UI 预览版 1.4.0 重构「晴日拼贴」和「灵感游乐场」两套界面。拼贴版使用侧边导航、纸片概览与双列课程卡片；游乐场采用横向导航、非对称头图、多列课程卡片与底部学习工具托盘。两套应用图标使用透明外缘，去除原白色底圈。在标题栏「我的课堂」与「隐私」之间点击「主题」，选择会保存；运行时 Dock、标题栏与页面图标同步切换。Finder/启动台安装图标为默认拼贴图标。切换时保留编辑器、媒体和用户面板布局。旧编辑部偏好兼容映射到游乐场。此版为预览发布，验证范围见 VERIFICATION.md。

## 安装

到 [GitHub Releases](https://github.com/He-He-He-He-He-He/ZhiyunAssistant/releases/tag/mac-v1.4.0-preview) 下载 `ZhiyunAssistant-Mac-1.4.0.dmg`，将“智云助手”拖到 Applications。也提供应用 ZIP 和独立源码 ZIP。一个安装包同时包含 Apple Silicon 与 Intel，最低 macOS 13。

当前是预览版，使用 ad-hoc 签名，尚未完成 Apple Developer ID 签名及公证。如果 macOS 阻止打开，请先核对发布中的 SHA256，再通过系统“隐私与安全”确认是否允许此应用。不要关闭系统整体安全保护。

Mac 与鸿蒙分别保存本机资料，当前没有跨设备自动同步。更新不会主动清理已有笔记、学习进度、收藏或离线课程。

## 学习与管理

- 今日课表、近两周、所有课程；课程和教师搜索、联动教师/课程、教室及学期筛选；日期选择支持月、年与横向翻月。课程广场放在导航最后。
- 课件与转写共享时间线和显示分页。连续相同课件可自动合并，转写按时间排序；中间隔着其他课件时不会合并。关闭“合并重复课件”可恢复原始页面。黑底内容受保护。
- 课件、转写、视频、笔记、课程问答、本页速览共六个独立功能区。用顶部横条移动，选中后四边与四角缩放；支持层级、锁定，以及针对相同功能区组合与窗口尺寸保存布局。弹出概览或跳转页面不会改变功能区层级。
- 宽窗口默认显示两页，四页课件按宽高比排成网格；课件与转写联动翻页。手动回看时视频继续播放，点“回到刚刚”恢复跟随。
- 主动打开视频后才加载媒体。支持播放/暂停、拖动预览时间、0.1–16 倍速、悬浮倍速滑轨和窗口全屏。全屏之外的界面保持应用配色，只有视频自身使用黑底。
- 多篇带时间和来源的富文本笔记。支持中间插入课件、图片、跨转写引用与 AI 格式内容；来源框的颜色可调，引用可跳回。支持重命名、管理、Markdown/HTML/文本导出，以及课程/日期/笔记目录的 ZIP 打包。
- 整门课、单课次收藏和稍后再看；每节学习进度独立保存。返回回到真实上一级，“我的课堂”回到最近使用的课堂列表。
- 本节下载及批量下载，可选课件、转写、视频；同时下载数量、队列顺序、单课暂停/继续、仅失败资源重试及保存可用内容。文件大小可确定时按实际字节显示进度，不能确定时明确显示已下载大小。删除会等待任务取消后清理文件。
- 分类缓存开关、详情与清理；普通缓存不清理笔记、离线课程、收藏和进度。断网不会自动退出登录。

平台实际提供的资源与账号权限决定可用内容。直播先请求已有课件和历史转写，再通过实时连接与定时历史同步补充；若平台没有提供某教室的早期转写，会说明缺失原因。只有平台提供可回放媒体时才能回看直播，不制造不存在的历史媒体。

## 键盘、鼠标和触控板

- 使用系统文字编辑、选择、菜单和剪贴板，支持 `⌘A / ⌘C / ⌘V`；部分区域也兼容 Control 快捷键。文字、数字直接交给系统输入法，不把鼠标按住拖选当成翻页。
- 聚焦课件后直接 `⌘C` 复制当前图片；全屏查看时复制预览中的图片。按住课件拖到其他应用时提供真实图片和 PNG 文件，不提供课程图片链接。
- 课程问答 Enter 发送、Shift＋Enter 换行；中文输入法提交候选保留系统行为。
- 点击文字区域或留白聚焦相应功能区。视频聚焦时空格播放/暂停，左右键各跳 15 秒；课件、转写和速览聚焦时左右键联动翻页。
- 触控板横向滚动翻页，纵向滚动阅读；选择文字期间保留原节点，不因实时转写或 AI 输出重建选区。
- 概览和问答课件选择支持触控板缩放；进入“选择”模式才允许拖动多选，滚动使用右侧固定滑轨。退出选择模式会清除选择。
- 双击课件打开独立全屏查看，单击退出；左右键、上一页/下一页和“回到最新”只切换查看的课件，不改变视频或转写进度。
- 功能区边缘显示对应缩放指针，布局可以向窗口外延伸，但顶部拖动横条始终保留在可操作范围。

## AI、隐私与费用

登录通过浙江大学官方认证页面，应用不保存校园密码。登录会话和 DeepSeek 密钥使用 macOS 钥匙串；本机资料按校园账号隔离。发布包不包含任何账号、密钥、登录会话或真实课程资料。

重启后自动尝试使用已保存的官方会话续接在线访问，响应中的新 Cookie 生效后再请求课程资料；登录错误不会保存成空课表。真正失效的学校会话仍需官方认证，断网保留本机登录身份和离线资料。

后台读取钥匙串不主动弹系统授权；同一进程复用已读取的会话和密钥，无新 Cookie 的响应不重复保存。临时签名更新后，若 macOS 拒绝静默读取，点击“恢复登录”或“恢复已保存的密钥”即可主动授权，无需先退出账号。正式签名的说明见 [分发说明](DISTRIBUTION.md)。

AI 仅在用户配置并启用后调用。课程问答默认以转写及课件时间索引为上下文，需要图像时才读取课件；也可指定结合课件、仅转写或整节课。问题中的资料范围优先于默认范围。本页速览可结合本页、前文、整节课、整门课之前或整门课资料，范围越大 token 越多。

速览和识图结果在本机复用，保留阅读位置；模型请求采用稳定课程前缀与末尾提问信息，以提高提供商缓存命中。问答记录完整保存，模型对话采用最近 20 轮窗口，课程资料仍按所选时间范围提供。图片识读使用最长边 1280 的 JPEG，避免反复发送原图。模型名称与接口依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/)，缓存依据 [上下文缓存说明](https://api-docs.deepseek.com/guides/kv_cache/)。

“跳过无实质讲解”默认关闭，启用前提示额外 API 费用。确认无转写的开头和结尾可以先跳过，AI 逐段识别的结果逐步生效；原始课程资料仍保留。AI 判断可能出错，关闭功能可恢复原文。

## 验证与平台差异

本次更新有完整页面 DOM 回归、隐藏真实 WebKit 流程、原生桥契约，以及两种 CPU 架构编译检查。具体通过数量与验证范围见 [VERIFICATION.md](VERIFICATION.md)。完整 WebKit 流程使用合成课件、转写和本机生成的测试视频，不读取用户钥匙串或真实课程，也不进行付费 AI 调用；这不能替代每个教室媒体源的真实验收。

这是行为与资料模型的迁移，不使用 ArkUI 在 Mac 运行。鸿蒙互联设备拍摄和鸿蒙系统的跨应用拖拽属于不同系统能力；Mac 使用系统文件选择、富文本编辑、拖拽与剪贴板，不承诺相同的系统跨设备流程。

## 独立构建

需要 macOS、Apple Command Line Tools、Node.js 20 或以上。普通构建不需要 DevEco。

```sh
npm ci
npm test
npm run verify
./tests/native-contract.sh
./tests/webkit-smoke.sh
./build.sh
```

构建输出位于 `build/`。`npm run sync:harmony` 是有相邻鸿蒙源码的维护者使用的可选同步步骤，独立构建使用已经提交的共享模块。测试依赖不会进入应用包。
