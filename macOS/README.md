# 智云助手 Mac 版

原生 macOS 窗口与系统 WebKit 客户端，使用智云助手的现有智云课程 API、时间线、连续重复课件识别和黑边处理模型。Mac 版本独立保存本机数据，与鸿蒙版不自动同步。

## 安装与运行

- 安装文件：`ZhiyunAssistant-Mac-1.0.0.dmg`。打开后将“智云助手”拖入 Applications。
- 也提供 `ZhiyunAssistant-Mac-1.0.0-PublicApp.zip`。
- 公开源码包：ZhiyunAssistant-Mac-1.0.0-PublicSource.zip。源码包包含独立构建所需的模型、构建脚本和锁定的测试依赖，不需要相邻的鸿蒙工程。源码包整理没有改变已发布安装包中的应用二进制或版本；安装文件与源码包的校验值见 [DISTRIBUTION.md](DISTRIBUTION.md)。
- 编译支持 Apple Silicon 与 Intel，最低 macOS 13。已在当前 Apple Silicon Mac 运行验证；Intel 是编译验证。
- 登录使用弹出的浙江大学官方页面。密码不经过自建登录接口、不保存校园密码。登录会话与 DeepSeek API 密钥使用 macOS 钥匙串。
- 当前为本机试用发行包，使用本地 ad-hoc 签名，尚未使用 Apple Developer ID 签名或完成公证。公开分发前需要正式签名、公证与权利材料。

## 已实现

课表、近两周与历史上课记录、课程广场搜索及日期选择，官方权限检查；整门课/单课次收藏与稍后再看；学习进度保存；课件与转写时间联动；连续重复课件合并、转写按原时间顺序归并；保守去黑边；课件概览、问答课件选择、课件单独全屏、跳转页数和时间；分段视频代理、播放/暂停、倍速、视频全屏、键盘跳转；可调整功能区布局；多篇课堂笔记、图片与课程引用、重命名、Markdown/HTML/纯文本导出、按课程/日期打包导出；离线课件、转写与视频下载、失败资源重试、保存可用内容、单独暂停与队列顺序、同时下载数量；分类缓存开关/查看/清理；课程问答和本页速览、AI 按需读取课件、流式输出、历史问答、速览缓存、其他课次时间引用、可选跳过无实质讲解。

课程读取以账号权限与平台实际提供的内容为准。直播先取平台历史课件和转写，再通过实时连接与定时历史同步补充；平台不提供历史转写时会明确提示，不能保证每个教室都有完整历史数据。视频只在功能区打开时获取，不默认自动播放；直播没有可回放源时不提供虚构的回放。

## 桌面交互

- 标准 macOS `⌘C / ⌘V / ⌘A`、原生文字选择和编辑菜单。
- 课程问答：Enter 发送、Shift＋Enter 换行；中文输入法候选提交保留系统行为。
- 聚焦视频：空格播放/暂停，左右方向键各跳转 15 秒。
- 聚焦课件/转写/速览：左右方向键翻页；触控板横向滚动翻页、纵向滚动阅读，不使用鼠标拖选作为翻页。
- 双击课件打开单独全屏查看，单击退出，左右切换只影响此全屏查看。
- 功能区顶部横条可拖动；选中后四边四角可调整；锁定和保存布局可在“布局”操作。
- 课件、转写与 AI 内容可插入笔记。笔记采用系统可编辑富文本流，不拦截数字键，不自行绘制光标。

## 数据与 API 费用

本机资料目录：`~/Library/Application Support/智云助手 Mac/`，各校园账号使用不同散列目录。登录身份、会话和密钥使用钥匙串；密码不落盘。普通缓存和离线内容、笔记、收藏、学习进度分开保存。断网不会注销身份，已经下载的课程可继续学习。

AI 按需调用，不内置历史对话里的 API 密钥。默认问答先给转写与课件时间索引，模型需要图像时才调用读取工具；识图结果与完成的速览缓存复用；课程材料按时间顺序，提问时刻放在消息末端，保持稳定资料前缀以提高 DeepSeek 缓存命中。课程图片需要识图时缩到最长边 1280，使用 JPEG。结合整门课和分析无实质讲解会增加 token，用前会说明。不开启这些功能时不会进行相应 AI 分析。

API 实现依据：[DeepSeek 视觉接口](https://api-docs.deepseek.com/guides/vision/)与[上下文缓存](https://api-docs.deepseek.com/guides/kv_cache/)。模型服务费用和可用模型以提供商为准。

## 验证记录与限制

- 19 项回归测试通过，覆盖授权拒绝、课件/转写边界、连续去重、课程层级收藏、返回路径、日期选择、问答资料范围、跨课次多个引用、黑底保护、受保护 HLS 下载拒绝等。
- 已使用当前账号的真实有权限课程验证课件/转写获取、视频实际时间推进、键盘空格暂停与方向键跳转；退出重启后账号恢复。
- 修复了登录窗口关闭释放时的崩溃。在线视频只读取有界字节段；下载视频使用系统流式下载到磁盘，离线视频按文件区间读取。
- AI 流式协议与工具调用已实现，未用聊天中以前提供的 API 密钥进行付费调用。不同教室的全部直播、独立音轨 HLS 与所有视频机位仍须逐类验证；独立音轨或平台版权保护格式不支持离线打包时会解释原因。
- 本版没有宣称和鸿蒙版的每一项系统能力完全一致：鸿蒙互联设备拍摄、系统跨应用拖拽、商城签名与商店发布属于各自系统的后续适配。

## 复现构建

源码已经包含 16 个适配后的浏览器模型；不读取相邻鸿蒙工程，不需要 DevEco，也不会在缺失模型时生成空文件。构建脚本会检查全部本地模块及其导出绑定后再编译。需要 Apple Command Line Tools 和 Node.js 20 或更新版本；Node 仅用于源码验证和开发测试，生成的应用运行不需要 Node 或 Electron。

开发测试依赖锁定的 jsdom（只用于测试，不进入运行包），可以从独立克隆目录执行：

```sh
npm ci
npm run verify
npm test
./build.sh
```

默认构建产物位于本目录的 `build/`。可用 `ZHIYUN_MAC_BUILD_DIR` 指定独立目录，避免覆盖已有构建。本次公开源码自包含修复只涉及构建、测试依赖和说明，未修改已发布 DMG/PublicApp ZIP 的二进制或版本。
