# 配色与外观

配色目录由 web/theme-catalog.js 定义：晴空（collage，默认）、紫藤（playful）、琥珀（film）。每套配色同时给出浅色与深色色板；原生稳定标识与旧主题ID映射同步在 Sources/App.swift。旧版 20 个主题ID会映射到最接近的配色，保存的偏好无需迁移。

外观模式（跟随系统 / 浅色 / 深色）保存在原生偏好 `appearanceMode`，启动时与配色一起注入页面。“跟随系统”时窗口不强制外观，页面通过 `prefers-color-scheme` 随 macOS 实时切换；浅色、深色会同时设定窗口外观，使标题栏控件可读。themes.js 按当前模式选择色板并计算可读的次要文字、强调色和按钮色，再把窗口画布颜色同步给原生标题栏。

主窗口的结构、控件与页面只有一套（app.css、study.css、agent.css）；themes.css 仅为每套配色增加少量饰面：紫藤更圆润，琥珀的标题与阅读内容使用宋体并带暖色纸本层次。切换配色或模式只更新呈现，保留学习中的播放器、笔记编辑器和选区，不额外读取课程接口。

外观页是 app.js 的 themes 路由，与收藏、笔记共用主窗口和返回栈。标题栏「外观」按钮只发出路由事件，不创建新窗口。配色选择通过 setAppearanceTheme 原生调用，模式通过 setAppearanceMode，均检查绑定主 WebView、来源、主框架和允许值，再保存偏好并同步 Dock 与标题栏图标。单击配色预览，同一配色连续点击第二次确认并返回上一页；原生确认失败时留在外观页。

运行 npm run capture:themes 会在隔离资料目录中启动真实生产首页，用合成课程资料逐套截取 1200×820 PNG 到 web/theme-previews，随后在真实主窗口内的外观页加载并点击全部缩略图验证。脚本还检查小窗口排版、截图完整比例与学习节点保留，并以深色外观逐配色原位切换学习页、检查可读性后截取到 build/ui-review/dark，结果在 build/theme-validation.json。调整首页或配色后应再次截取，随后构建。

语义图标在 theme-icons.js 中统一定义，各配色可调整线宽与端点；日期、翻页等具有不同形状，其他操作保持统一语义。禁止用字体箭头或网格字符替代日期和日历图标。
