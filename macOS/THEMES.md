# 主题与真实首页预览

主题目录由 web/theme-catalog.js 定义，原生稳定标识同步在 Sources/App.swift。

主窗口使用 theme-library.css 和 theme-home.js 渲染全部真实课程与操作。切换主题通过事件更新呈现；学习中的播放器和笔记节点保留，不额外读取课程接口。

主题选择是 app.js 的 themes 路由，与收藏、笔记共用主窗口和返回栈。标题栏按钮只发出路由事件，不创建新窗口。选择通过 setAppearanceTheme 原生调用，检查绑定主 WebView、来源、主框架和 20 个允许值，再保存偏好并同步 Dock 与标题栏图标。

运行 npm run capture:themes 会在隔离资料目录中启动真实生产首页，用合成课程资料逐套截取 1200×820 PNG 到 web/theme-previews，随后在真实主窗口内的主题选择页加载并点击全部缩略图验证。脚本还检查小窗口排版、截图完整比例与学习节点保留，结果在 build/theme-validation.json。重新调整主题首页后应再次截取，随后构建。

语义图标在 theme-icons.js 中统一定义，20 个主题选择各自的线宽、端点和几何家族；日期、翻页等具有不同形状，其他操作保持统一语义。theme-icons.css 负责主题色、尺寸和边框。禁止用字体箭头或网格字符替代日期和日历图标。专项还截取 20 套真实日历页面到 build/theme-calendars，作为排版和图标验收，不打包用户课程图片。

主题页面单击预览，同一主题连续点击第二次确认并返回上一页，包含快速双击；原生确认失败时留在选择页。并发的同一主题选择合并，确认后只返回一次。胶片主题图标改为内置 imagegen 生成的书页与胶片结合图案，生成说明见 ICON_DESIGN.md。
