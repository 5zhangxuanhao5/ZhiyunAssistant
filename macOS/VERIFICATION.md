WebKit 流程在隐藏临时窗口和本机服务器运行，不主动激活用户正在使用的窗口。课件/转写为人工合成，视频由测试程序在本机生成；测试严格阻止外部连接，不读用户钥匙串、真实课程或个人资料，不产生付费 AI 请求。结束时没有 page error 或未处理 Promise 拒绝。

## 可复现命令

```sh
npm ci --ignore-scripts
npm test
npm run verify
npm run test:native
npm run test:webkit
npm run build
```

原生契约与完整 WebKit 测试需要 macOS 以及可用的 Apple Command Line Tools / 系统 WebKit。测试创建临时目录，退出时删除自己的临时内容，不清理应用用户资料。

## 没有由这些测试证明的事项

没有覆盖所有真实教室、摄像机、媒体格式和物理鼠标/触控板型号；浏览器选区和事件验证不等于所有外设的人工验收。直播历史课件、历史转写和可回放视频是否存在由平台决定。AI 流式协议、资料范围、识图请求和缓存代码有测试，未通过本轮付费调用证明模型回答质量。没有完成 Developer ID 发行签名或 Apple 公证。

上述恢复会话检查使用隔离的 Cookie 和本机 URLProtocol，不读取真实账号。学校真实会话是否还能续接，以及不同应用是否接受拖入的图片，需要实际使用场景确认。
